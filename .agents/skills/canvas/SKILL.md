# Canvas — Interactive Visual Workspace

Use this skill when designing or reviewing visual UI components, creating interactive diagrams, exploring layout options side-by-side, or previewing front-end experiences.

## Principles

1. **Instant Visual Feedback**: Provide self-contained, previewable HTML/CSS/React mockups.
2. **Responsive Matrix**: Always preview components across standard viewports:
   - Desktop: 1440px
   - Tablet: 1024px / 768px
   - Mobile: 390px
3. **Design System Adherence**: Respect project CSS tokens, typography scale, semantic color variables, and spacing grids.
4. **Interactive States**: Model and display hover, active, focus-visible, and disabled states clearly.
