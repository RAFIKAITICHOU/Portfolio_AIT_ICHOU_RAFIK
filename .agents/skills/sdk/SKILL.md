# Agent SDK — Programmatic Harness & Orchestration

Use this skill when interacting programmatically with the Agent SDK, writing custom orchestration scripts, or wiring agent event listeners.

## Key APIs

- Tool registry and invocation.
- Subagent lifecycle management (`spawn`, `message`, `kill`).
- Task backgrounding and reactive event wakeups.
- Sandbox boundary enforcement and permissions.
