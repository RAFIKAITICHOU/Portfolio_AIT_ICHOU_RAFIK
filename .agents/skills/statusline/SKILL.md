# Statusline — Terminal Context & Metric Indicators

Use this skill to inspect, customize, or render dynamic terminal statuslines for coding agents and CLI sessions.

## Monitored Indicators

- Active Git branch, clean/dirty state, and upstream delta.
- Current active model and token usage indicators.
- Workspace environment and sandbox isolation mode.
- Background process and subagent concurrency counter.
