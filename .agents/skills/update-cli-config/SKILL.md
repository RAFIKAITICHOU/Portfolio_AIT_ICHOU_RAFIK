# Update CLI Config — Agent Environment Configuration

Use this skill to view, validate, or modify settings in agent CLI configuration files.

## Common Configurations

- Approval modes: `allowlist`, `auto-review`, `unrestricted`.
- Terminal notification preferences and sound alerts.
- Default model selection and temperature overrides.
- Sandbox network whitelist and volume mount permissions.
